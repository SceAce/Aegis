# 测试辅助代码规则

继承 [测试规则](../AGENTS.md)。这里只放测试 fixture、子进程、barrier 和运行器，不实现另一套产品行为。

- helper 提供原始输入/受控故障/证据，预期值由独立规则确定；不调用被测实现来生成 expected。
- 恢复测试用真实子进程、独立工作区和明确同步点，保留真实事件/效果/退出码。
- 超时、信号、子进程异常与脚本失败都不能被管道、最后一条 echo 或空结果掩盖为 exit 0。
- runner 仅执行显式脚本清单，按真实依赖选择 source resolver，不运行真实 provider/目标集合。
- 不在 helper 中读取用户默认凭据、注册真实网络 provider 或改变嵌套 Pi 配置。

改运行器时验证至少一个成功与一个失败子脚本的退出传播；改共享 fixture 时检查使用它的测试，不只检查 helper 语法。
