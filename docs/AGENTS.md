# 文档开发规则

适用于 docs/。根入口和 [固定规则](DEVELOPMENT_RULES.md) 负责全局原则；本目录负责契约、任务、操作说明、审计与历史记录。

- 当前规则、任务计划、实现状态和验收证据分开。计划/草案不能写成已实现，内部验证不能写成外部接受。
- 临时状态、提交基线、失败清单和阶段授权写任务/报告，不写任何自动加载的 AGENTS.md。
- 历史报告保留当时事实和路径；当前操作说明跟随代码更新，跨迁移查 [路径映射](MODULE_PATH_MAP.json)。
- 只链接必要的当前契约/章节，不把全部历史任务设为默认必读；引用历史时标明基线和适用限制。
- 记录实际命令、退出码、证据位置与未运行项；公开文档不复制凭据、flag、完整私有会话或无限制原始输出。
- 修改规则须同步冲突的当前入口，保持根 → 工程 → 模块的继承；不以模块规则扩大用户授权。
- archive/ 只保存历史，不从归档加载当前开发指令。需要追溯时按文件读取。

文档修改检查相对链接、代码/测试文件名、命令路径和规则一致性即可；没有行为变更时不运行全套产品测试。
