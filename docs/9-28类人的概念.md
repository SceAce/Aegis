# codex

我的建议是：

不要先把“记忆模块”单独做完，也不要先把所有基础设施做完再碰记忆。应该先完成一个最小的“学习闭环”，其中记忆从第一天就存在，但只实现最基础的情景记忆；复杂的经验提纯、世界模型和自我成长机制放在闭环跑通之后。

因为记忆本身不是学习。只有下面这条链成立时，记忆才有意义：

观察 → 形成假设 → 采取行动 → 获得反馈 → 记录经历 → 修正判断 → 再次行动

如果没有可靠反馈，记忆只能变成模型叙事的存档；如果没有行动，经验无法验证；如果没有验证，所谓“成长”只是知识库膨胀。

一、不要把“趋向人类”当成一个直接工程目标

“像人类一样学习”不是一个可直接验收的目标。人类也不是单纯依靠记忆，而是同时具备：

先天结构：因果、主体、时间、空间、他者等基本假设；
经验学习：从具体经历中发现规律；
理性推演：把规律组合、迁移到新情况；
社会学习：从他人的示范、语言和反馈中学习；
行动反馈：通过现实结果修正自己；
元认知：知道自己什么时候不确定、什么时候可能错。

所以目标应拆成可测量的能力：

从少量经历中学会规律；
能把规律迁移到相似但未见过的问题；
能区分“我观察到了”和“我推测出来了”；
失败后会改变后续行为；
发现环境变化后会让旧经验失效；
在不确定时会主动观察，而不是胡乱行动；
能接受人的示范和纠正；
不会因为一次成功就把偶然现象当成真理。

二、经验主义和理性主义不应该二选一

比较合适的组合是：

 方向        在 Agent 中负责什么
━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 经验主义    提供观察、结果和反例
──────────  ────────────────────────────────────────────
 理性主义    提供概念、因果结构、组合和推演
──────────  ────────────────────────────────────────────
 实用主义    决定现在做什么，按收益、成本和信息价值排序
──────────  ────────────────────────────────────────────
 社会学习    接受人的语言、示范、纠错和规范

可以把它浓缩成一句话：

经验提供材料，理性组织材料，实践检验材料，社会反馈修正材料。

单独走经验主义，会得到“见过什么就记什么”的模式匹配系统；单独走理性主义，会得到脱离现实反馈的推理系统。真正接近人类的过程是：

观察事实
  → 提出解释
  → 预测结果
  → 采取行动验证
  → 根据结果保留、修改或放弃解释

这比“让模型多读知识”更接近学习本身。

三、目前应该优先做什么

建议按这个顺序推进：

### 1. 先定义最小学习环境

需要有一个 Agent 可以反复面对的、结果可判断的环境。环境可以很小，例如：

一个有隐藏规则的工具使用任务；
一个简单模拟器；
一个带状态变化的文件或 API 系统；
一个小型游戏或网格世界。

环境必须能回答：

Agent 看到了什么？
Agent 做了什么？
环境发生了什么？
这个行动是否达到目标？
为什么成功或失败？

没有这个环境，记忆和经验无法验证。

### 2. 实现最小情景记忆

第一版只存：

当时的环境状态
当时的目标
观察到的内容
执行的动作
得到的结果
结果的证据

暂时不要急着做语义总结、人格、长期世界观或自动生成经验。先保证 Agent 能准确回忆：

“我在什么条件下做了什么，结果是什么。”

这是学习的原始材料。

### 3. 实现失败后的行为变化

这是比“记住成功案例”更重要的验收点。

例如：

第一次：动作 A 失败
第二次遇到相同条件：不再盲目重复 A，而是先观察或尝试 B

如果记忆写入了，但行为完全不变，那只是日志系统，不是学习系统。

### 4. 再实现经验提纯

经验不是一段总结文本，而应该是：

条件 C
  → 建议动作 A
  → 预期结果 P
  → 证据数量
  → 失败数量
  → 适用范围

经验必须能被重新测试。不能因为模型写了一句“以后应该先检查 X”，就算学会了。

### 5. 最后才做长期语义记忆和技能库

只有当情景记忆、反馈和经验提纯都稳定之后，才值得加入：

概念抽象；
跨任务迁移；
技能编译；
世界模型；
主动学习；
多 Agent 协作；
自我修改。

否则这些模块很容易变成无法验证的复杂层。

四、建议采用三种不同时间尺度的记忆

人类式学习至少需要三个循环：

快速循环：当前任务中的观察、行动、反馈
中速循环：一次任务结束后的经验提炼
慢速循环：长期概念、技能和世界模型的调整

对应到工程上：

工作记忆：只服务当前任务，会话结束后大部分清除。
情景记忆：保存具体经历，作为未来学习和审计材料。
程序/语义记忆：从多次经历中提炼出的规则和技能，必须经过验证才能影响行为。

重要的是：

长期规则不能覆盖原始经历；规则错了，还必须能回到原始经历重新检查。

五、最小可行的“新生 Agent”不应该是空白模型

新生不等于完全没有先验。人类婴儿也带着许多先天结构。你的 Agent 至少需要一组稳定的“先天能力”：

能区分观察、猜测和结果；
能记住动作及其后果；
能表示不确定；
能提出简单假设；
能预测下一步结果；
能从失败中修改策略；
能遵守安全和权限边界；
能接受外部示范和纠正；
能在信息不足时优先观察。

这些是学习机制，不是具体知识。它们可以放在 ROM 中；具体经验则进入可修改的记忆系统。

六、当前最合适的工程优先级

我建议现在不要做完整的多模型调度、Codex/DSH 接线、复杂 RAG 或无限扩展的 Agent 平台。优先级应是：

学习闭环契约
  → 一个可验证的小环境
  → 事件与情景记忆
  → 失败驱动的行为改变
  → 规则/经验提纯
  → 规则回放与反事实验证
  → 再扩展到多模型和多领域

第一阶段的成功标准可以非常具体：

Agent 第一次不知道规则；
通过少量尝试得到反馈；
能保存经历；
第二次行动比第一次更好；
换一个相似任务仍然能迁移；
环境改变后，旧经验会被暂停或修正；
Agent 能明确说出哪些是事实、哪些是假设、哪些还未知。

这比先做一个完整的“记忆库”更重要。我们真正要先搭的是学习机制，记忆只是其中的长期存储部分。
